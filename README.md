# 曲园自习打卡助手

面向曲阜师范大学考研备考学生的轻量自习工具，帮助用户把每日专注、连续打卡和备考计划变成看得见的进度。

## 功能

- 自习计时：选择科目，开始、暂停、继续、结束并保存
- 今日看板：今日专注、连续打卡、本周累计和科目专注分布
- 打卡日历：单日专注满 25 分钟自动打卡，按日期查看明细
- 备考计划：考试倒计时、每日时间块、固定任务时间轴和可自定义的科目分配比例
- 经验卡片：备考方法卡与本地收藏
- 本地存储：数据写入浏览器 `localStorage`，无需登录
- 示例数据：一键载入演示数据，方便评审快速查看完整状态

## 技术栈

- Vite 5
- React 18
- TypeScript
- 原生 CSS
- SVG 环形图
- 浏览器 localStorage

项目为纯前端静态应用，不依赖后端、数据库或外部 API。

## 本地运行

```bash
npm ci
npm run dev
```

打开 `http://localhost:5173`。

## 构建

```bash
npm run build
```

构建产物位于 `dist/`，可直接作为静态站点部署到 Nginx、对象存储或其他静态托管服务。

## 目录结构

```text
src/
  components/   通用组件与计时浮层
  data/         科目、任务、经验卡和示例数据
  lib/          日期、格式化和计划计算工具
  pages/        今日、日历、计划、经验页面
  store/        应用状态与 localStorage 持久化
  styles/       设计变量与页面样式
```

## 数据说明

数据保存在当前浏览器的 localStorage 中，不会上传到服务器。更换浏览器或清理站点数据后，记录不会自动同步。

## 设计方向

新中式学习手账风格，使用墨青、杏坛红、宣纸米和银杏金，结合日晷计时环、银杏叶打卡和曲园印章等校园元素。
